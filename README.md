# LP Tracker — веб-дашборд

Тот же расчёт, что в приложении, но в браузере: позиции Uniswap V3/V4 и PancakeSwap V3 читаются прямо из блокчейна
(publicnode), Krystal даёт только номера V4-позиций и суммы вложений для PnL, свечи — GeckoTerminal, пулы монеты — DexScreener.
Сервера нет: это три статических файла, всё считается в браузере.

Адреса кошельков хранятся только в браузере (localStorage). Быстро добавить несколько — ссылкой
`…/index.html#w=Имя:0xадрес,Имя2:0xадрес` (часть после # не уходит ни на какой сервер).

Запустить локально: `python3 -m http.server 8765` в этой папке и открыть http://localhost:8765.
